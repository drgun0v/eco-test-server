INSTALL NOTES

1) Configure config.lua.

Framework modes:
- auto
- esx
- qb / qbcore
- qbox / qbx_core
- standalone

Inventory modes:
- auto
- ox / ox_inventory
- esx
- qb / qbcore
- qbox / qbx_core
- none

2) If tickets are enabled, add the bus_ticket item to your inventory.

ox_inventory/data/items.lua:

['bus_ticket'] = {
    label = 'Bus Ticket',
    weight = 0,
    stack = true,
    close = true,
    description = 'A ticket for bus travel.'
}

3) Add the bus_ticket.png image to your inventory image folder.

For ox_inventory:
ox_inventory/web/images/

For QBCore inventory:
your inventory html/images folder

4) Ensure the resource after your framework and inventory.

Example server.cfg:

ensure es_extended
ensure ox_inventory
ensure tdev_bus

Or:

ensure qb-core
ensure ox_inventory
ensure tdev_bus

Or:

ensure qbx_core
ensure ox_inventory
ensure tdev_bus

5) Restart your server.
